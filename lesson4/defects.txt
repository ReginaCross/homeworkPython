ДЕФЕКТЫ ОБНАРУЖЕННЫЕ В КЛАССЕ StringUtils

============================================
ДЕФЕКТ #1: Функция capitalize
============================================
СЕРЬЕЗНОСТЬ: Низкая
ПРИОРИТЕТ: Средний
СТАТУС: Открыт

ОПИСАНИЕ ПРОБЛЕМЫ:
Функция capitalize не обрабатывает строки, начинающиеся с пробела.
В текущей реализации строка " skypro" преобразуется в " skypro" вместо " Skypro".

ШАГИ ДЛЯ ВОСПРОИЗВЕДЕНИЯ:
1. Вызвать функцию capitalize(" skypro")
2. Получить результат " skypro"

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
" Skypro"

ФАКТИЧЕСКИЙ РЕЗУЛЬТАТ:
" skypro"

============================================
ДЕФЕКТ #2: Функция trim
============================================
СЕРЬЕЗНОСТЬ: Низкая  
ПРИОРИТЕТ: Низкий
СТАТУС: Открыт

ОПИСАНИЕ ПРОБЛЕМЫ:
Функция trim удаляет только пробелы в начале строки, но не другие whitespace-символы
(табуляции, переносы строк и т.д.)

ШАГИ ДЛЯ ВОСПРОИЗВЕДЕНИЯ:
1. Вызвать функцию trim("\tskypro")
2. Получить результат "\tskypro"

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
"skypro" (или обработка всех whitespace-символов)

ФАКТИЧЕСКИЙ РЕЗУЛЬТАТ:
"\tskypro"

============================================
ДЕФЕКТ #3: Функция contains
============================================
СЕРЬЕЗНОСТЬ: Средняя
ПРИОРИТЕТ: Высокий
СТАТУС: Открыт

ОПИСАНИЕ ПРОБЛЕМЫ:
Функция contains чувствительна к регистру, что может быть неочевидно для пользователя.
Документация не упоминает о чувствительности к регистру.

ШАГИ ДЛЯ ВОСПРОИЗВЕДЕНИЯ:
1. Вызвать функцию contains("SkyPro", "s")
2. Получить результат False

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
True (или явное указание в документации о чувствительности к регистру)

ФАКТИЧЕСКИЙ РЕЗУЛЬТАТ:
False

============================================
ДЕФЕКТ #4: Функция list_to_string
============================================
СЕРЬЕЗНОСТЬ: Низкая
ПРИОРИТЕТ: Низкий
СТАТУС: Открыт

ОПИСАНИЕ ПРОБЛЕМЫ:
При использовании пустого разделителя происходит неожиданное поведение -
строки склеиваются без пробелов.

ШАГИ ДЛЯ ВОСПРОИЗВЕДЕНИЯ:
1. Вызвать функцию list_to_string(["a", "b", "c"], "")
2. Получить результат "ab c"

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:
"abc" (полная конкатенация) или более предсказуемое поведение

ФАКТИЧЕСКИЙ РЕЗУЛЬТАТ:
"ab c"
